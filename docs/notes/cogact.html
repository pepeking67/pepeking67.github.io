VLA_6. CogACT: A Foundational Vision-Language-Action Model for Synergizing Cognition and Action in Robotic Manipulation

Li et al.

Original paper ↗

Introduction

Unlike previous works that directly repurpose VLM for action, we propose a componentized VLA that a specialized action module conditioned on VLM output. We use the cognitive information by VLM to condition the action prediction process. We employ diffusion-based transformers(DiT) to do this process. In addition, we propose an adaptive action ensemble(AAE) to fuse the past action in an adaptive manner.

Architecture

We componentize the model into 3 parts: 1. Vision module 2. Language module 3. Action module Vision and language module follows the Prismatic VLM, which is base VLM of openVLA. For vision module, the image observation is fed into the DINOv2 and SigLIP models, and then produce visual perceptual tokens V={v1,v2,⋯ ,vNv}\mathcal{V}=\{ v_1, v_2, \cdots, v_{N_v} \}V={v1​,v2​,⋯,vNv​​}. LLAMA-2 model is applied as the language module backbone. The language instruction l\bm{l}l is converted into linguistic tokens T={l1,l2,⋯ ,lNT}\mathcal{T}=\{ l_1, l_2, \cdots, l_{N_\mathcal{T}} \}T={l1​,l2​,⋯,lNT​​}. These tokens are concatenated with V\mathcal{V}V and an additional learnable cognition token c\bm{c}c, and processed by the model using a causal attention mechanism. The resulting output is cognition token ftc\bm{f}_t^cftc​.

Diffusion action module

Action module takes the cognition feature ftc\bm{f}_t^cftc​ along with noisy actions (ati,at+1i,⋯ ,at+Ni)(a_t^i, a_{t+1}^i, \cdots, a_{t+N}^i)(ati​,at+1i​,⋯,at+Ni​) as input, where iii denotes the current denoising step. We add step information iii with a sinusoidal positional encoding. Since Transformers struggle to directly process the integer iii, it is encoded using sine and cosine functions for positional encoding. Model predicts action chunk (at,at+1,⋯ ,at+N)(a_t, a_{t+1}, \cdots, a_{t+N})(at​,at+1​,⋯,at+N​).

Adaptive action ensemble

Model predicts actions for multiple time steps. ACT is to execute actions consecutively. However, this does not fully leverage the visual information. ACT also introduced a temporal ensemble strategy that combines current actions from both present and past using preset aggregation weights. But action tasks can have different modes(ex. right or left move), so that simply aggregating them could result in an action that is suboptimal. Instead of generating a single action, the model produces action chunks, resulting in multiple action candidates for a given time step ttt, as shown in the figure above. While previous methods simply averaged these predictions, the adaptive action ensemble(AAE) strategy computes weights based on their similarity to the prediction made at the current time step.
