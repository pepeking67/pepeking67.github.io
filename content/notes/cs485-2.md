## Weak Learners
![](notion-file-block://0390ad69-a5f8-83f6-8b30-01a7d8fa9324/7d0587f9-dcae-4af9-9d64-7cdeb697eb42?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
We use the terms “split function,” “test function,” and “weak learner” interchangeably
Each node has associated a different test function
$$
h(v,\theta_j)=\{0\ or\ 1\}
$$
0과 1은 각각 false, true를 의미한다
$`\theta_j`$는 j node에서의 test function의 parameters들을 의미한다
데이터 포인트 v는 split node에 도착하면 test function의 결과에 따라 왼쪽 또는 오른쪽 노드로 이동한다
<empty-block/>
weak learner model의 parametrization을 $`\theta=(\phi,\psi,\tau)`$로 나타낸다
$`\phi`$는 filter function으로 entire vector v 에서 일부 features들을 선택한다
$`\psi`$는 데이터를 나누기 위한 geometric primitive를 정의한다 
(an axis-aligned hyperplane, an oblique hyperplane, a general surface etc.)
$`\tau`$는 threshold이다
<empty-block/>
### Linear
$$
h(\mathbf{v}, \boldsymbol{\theta}) = \left[\tau_1 > \phi(\mathbf{v}) \cdot \psi > \tau_2\right]
$$
여기서 \[\]는 indicator function이다
지시 함수는 $`\mathbb{1}_A(x) := \begin{cases} 1 & x \in A \\ 0 & x \notin A\end{cases}`$ 이러한 형태이고, 이는 $`[x\in A]`$로 나타낼 수 있다
즉, \[\] 안의 식을 만족하면 1, 아니면 0을 출력한다
<empty-block/>
2D의 경우 $`\phi(v)=(x_1\ x_2\ 1)^T`$with $`\psi \in R^3`$ a generic line in homogeneous coordinates으로 설정
single-inequality test를 위해 $`\tau=\infin\ or\ \tau_2=-\infin`$으로 설정한다
$`\psi,\ \tau`$들은 학습 과정을 거치면서 결정된다
![](notion-file-block://42c0ad69-a5f8-8331-a4a8-811c039fab3b/08bb99e1-48c1-4002-826d-b7faf761c061?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
### Non-Linear
$$
h(\mathbf{v}, \boldsymbol{\theta}) = \left[\tau_1 > \phi(\mathbf{v}) \psi \phi(\mathbf{v}) > \tau_2\right]
$$
2D의 경우 $`\phi(v)=(x_1\ x_2\ 1)^T`$로 둔다
$`\psi \in R^{3\times 3}`$이 conic section in homogeneous coordinates를 나타낸다
이 conic section이 non-linear hypersurface를 나타낸다
computationally expensive
<empty-block/>
### Axis-aligned
special case of linear weak learned model: $`\psi`$ is aligned with one of the axes of the feature space
selects one dimension of the input $`v\in R^d`$
$$
h(\mathbf{v}, \boldsymbol{\theta}) = \left[\tau_1 > \phi(\mathbf{v}) \cdot \psi > \tau_2\right]
$$
In 2D, $`\phi(v)=(x_1\ x_2\ 1)^T`$, $`\psi = (1\ 0 \ \psi_3)`$ or $`\psi=(0 \ 1\ \psi_3)`$
아니면 단순히 $`h(v,\theta)=[x_i>\tau]`$, for ant $`i\in\{1, ... ,d\}`$
굉장히 빠르다
<empty-block/>
### Two-pixel test
special case of linear weak learner
axis-aligned보다 살짝 complex하다
$$
h(\mathbf{v}, \boldsymbol{\theta}) = [x_i - x_j > \tau] \quad \text{for any } i, j \in \{1, \ldots, d\} \text{ and } i \neq j
$$
axis-aligned보다 dimension을 하나 더 사용한다
approximation of the gradient로 볼 수 있다
<empty-block/>

### Entropy
$$
H(x) = \sum_x P(x) h(x) = -\sum_x P(x) \log P(x)
$$
⇒ The average amount of h(x)
entropy is more higher when distribution is uniform
<empty-block/>
Shannon entropy를 사용할 건데 
$$
H(S) = -\sum_{c\in C} p(c) \log p(c)
$$
S: set of training points, c: class label
위의 예시 사진에서 보면 분할 이후에 엔트로피가 낮아지고 가지고 있는 information이 증가한 것을 확인할 수 있다
이를 수치적으로 information gain으로 표현하면 다음과 같다
$$
I(S, \theta) = H(S) - \sum_{i \in \{L, R\}} \frac{|S^i|}{|S|} H(S^i)
$$
![](notion-file-block://8a00ad69-a5f8-8282-9f53-810824fa8b78/8a640c72-c752-4763-9f0f-c3eca2bb71cd?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
이런 식으로 수직으로 잘랐을 때 더 좋은 경우가 있다
이런 식으로 information gain을 최대화시켜야 한다

## Random Decision Forest
ensemble of randomly trained decision trees
component trees are all randomly different from one another
decorrelation between the individual tree prediction ⇒ generalization and robustness
<empty-block/>
앙상블 러닝이기 때문에 randomness를 다음과 같이 부여한다
1. bagging: randomization on data
2. randomized feature selection (randomized node optimization)
<empty-block/>
### Randomized Node Optimization
decision tree에서는 각 노드에서 entire parameter $`\theta \in T`$에 대해서 optimization 을 진행했다
하지만 이는 비효율적이다
그래서 각 노드 j에 대해서 $`T_j \sub T`$를 사용한다
![](notion-file-block://b440ad69-a5f8-8389-b387-0193864d850e/3c424d93-35a7-45e0-90ca-63767fbaef4b?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
amount of randomness: $`\frac{|T_j|}{|T|}`$
T의 크기가 infinity라고 하면 parameter $`\rho=|T_j|`$를 도입할 수 있다
$`\rho`$를 통해 degree of randomness를 나타낼 수 있다
$`\rho`$가 커질수록 랜덤성이 작아진다 (T와 가까워지기 때문에)
너무 작아지면 real optimization을 얻지 못할 수 있다
$`\rho`$는 랜덤의 정도 뿐만 아니라 다른 tree와의 correlation을 나타낸다
$`\rho`$가 커질수록 트리들이 비슷하고, 작을수록 decorrelation ← 트리의 구조 이런 게 다름
![](notion-file-block://df80ad69-a5f8-82a4-84fd-01d105083667/af11688e-0e06-4f7e-b675-d5ee57468efc?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
fixed depth에서 radomized feature가 strength를 낮출 수 있다
<empty-block/>
### Committee Machine
다양한 모델 $`y_t(x), \quad t = 1, \ldots, T`$
output: $`y_t(x) = h(x) + \epsilon_t(x)`$
h: true value, $`\epsilon`$: error
<empty-block/>
average sum-of-squares error: $`\mathbb{E}\left[ \{ y_t(x) - h(x) \}^2 \right] = \mathbb{E}\left[ \epsilon_t(x)^2 \right]`$
average error: $`E_{\text{av}} = \frac{1}{T} \sum_{t=1}^{T} \mathbb{E}[\epsilon_t(x)^2]`$
<empty-block/>
committee machine: 
$$
y_{\text{com}}(x) = \frac{1}{T} \sum_{t=1}^{T} y_t(x)
$$
expected error:
$$
E_{\text{com}} = \mathbb{E} \left[ \left( \frac{1}{T} \sum_{t=1}^{T} y_t(x) - h(x) \right)^2 \right]




$$
$`\mathbb{E}[\epsilon_i(x) \epsilon_j(x)] = 0`$를 가정하면 
$$
= \mathbb{E} \left[ \left( \frac{1}{T} \sum_{t=1}^{T} \epsilon_t(x) \right)^2 \right]
= \mathbb{E} \left[ \frac{1}{T^2} \left( \epsilon_1^2 + \epsilon_1 \epsilon_2 + \epsilon_2^2 + \cdots \right) \right]
$$
<empty-block/>
$$
E_{com}=\frac{1}{T}E_{av}
$$
실제로는 에러들이 correlated되어 있지만 $`E_{com}\leq E_{av}`$로 생각할 수 있다
<empty-block/>
모든 트리들은 독립적으로 학습되고 병렬적으로 학습된다
testing point는 root에서 시작해서 모든 트리에 동시에 입력된다
⇒ 효율적이다
<empty-block/>
tree predictions들은 다음과 같이 결합한다

# Bag of Words (BoW)
## visual object categorization
새로운 이미지가 주어졌을 때 이 이미지를 효율적으로 categorize하는 것이다
이 과정은 generic해야 한다
variation을 처리할 수 있어야 한다
<empty-block/>
이를 위해서 bag of (visual) words 기법을 사용한다
bag of visual words는 histogram of occurrences of particular image patterns in a given image
BoW의 방식은 효율적이고 affine transformation (translation, scaling, reflection, rotation)에 invariant
이외에도 occlusion, lighting, intra-class variation에도 잘 적용할 수 있다
<empty-block/>
## Bag of Words
text를 bag of its words로 간소화한다
문법이나 단어 순서들을 disregarding한다 (multiplicity는 유지)
frequency of occurrence of each word를 feature로 사용하여 classification에 사용한다
![](notion-file-block://1b70ad69-a5f8-8365-ab7b-01c43ae64227/0bb98550-9da0-4550-87de-5aa5dc8bb579?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
visual words: base elements to describe an image
object image는 collection of visual words
independent features를 codewords라 한다 (representativeof similar patches)
그러면 이미지의 patch들은 codeword들로 매핑되고 codewords의 histogram으로 나타낼 수 있다
![](notion-file-block://0f60ad69-a5f8-822d-a34e-817e13172755/54b502f3-4b9c-4004-be4c-cb04d4b01dd2?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
테스팅에서는 이 BoW를 feature vector로 사용하여 image의 class를 찾는다
<empty-block/>
테스트를 진행할 때 새로운 이미지의 descriptors를 추출할 때 categorization task와 무관한 변환에 대해서 inavriant해야 한다
vocabulary size가 충분히 커서 이미지를 잘 표현할 수 있어야 하지만 너무 크면 노이즈까지 표현하게 되는 문제가 생기기 때문에 적절한 크기를 선택하는 것이 중요하다
codeword에는 눈, 코, 입과 같이 intuitive meaning을 가지지는 않는다
<empty-block/>
트레이닝을 할 때 테스트와 마찬가지로 터음에 디스크립터를 추출하고, 클러스터링을 통해 클러스터 중심들로 코드북(vocabulary)을 만든다. 이 코드북을 사용해서 BoW를 추출한다
이를 feature vector로 사용해서 multi-class classifier를 사용한다
전반적으로 가장 높은 정확도를 보이는 vocabulary size와 classifier parameter를 결정한다
<empty-block/>
![](notion-file-block://9b80ad69-a5f8-82cb-9713-81eb270f0576/ee68b643-8434-4548-8cac-7180651ff5dd?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
왜 디스크립터가 affine transformation에 invariant해야 하냐면 디스크립터는 repeatable해야 하기 때문이다
가장 대표적인 디스크립터 추출 방식은 SIFT이다
4\*4 grid의 8 orientations의 Gaussian gradient를 계산하여 이를 디스크립터로 사용한다 (128dim)
<empty-block/>
visual word (real-valued descriptor vectors)는 Euclidean distance를 통해 비교한다
