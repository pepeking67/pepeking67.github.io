## Course overview

OpenCV University's six-module bootcamp introducing practical vision-language models through Python and Colab notebooks.

### Topics covered

- CLIP and multimodal embeddings.
- Zero-shot image classification with CLIP.
- Qwen2.5-VL for image captioning and zero-shot object detection.
