Introduction

DQN still handles only low-dimensional action spaces such as curse of dimensionality. A naive application of actor-critic method with neural function approximators can solve this problem. Deterministic policy gradient(DPG) learns a deterministic policy a=μ(s)a=\mu(s)a=μ(s) as an actor on continuous action spaces and an action-value function Q(s,a)Q(s,a)Q(s,a) as a critic. We can make this algorithm stable using two innovations of DQN. 1. replay buffer 2. target Q-network DDPG is designed to handle continuous action spaces by replacing DQN's argmax operation with a neural network.

This is based on the deterministic policy gradient theorem, analogous to stochastic PG theorem. It applies chain rule to the expected return with respect to the actor parameters. Its contribution is to provide modifications to DPG, inpired by DQN, which allow it to use neural network function approximators to learn in large state and action spaces. DDPG adapts DQN's two innovations: replay buffer and target network. But the target network is modified for actor-critic and using soft target updates: θ′←τθ+(1−τ)θ′\theta' \leftarrow \tau \theta + (1-\tau)\theta'θ′←τθ+(1−τ)θ′ with τ≪1\tau \ll 1τ≪1. When learning from low dimensional feature vector observations, the different components of the observation may have different physical units. This can make it difficult for the network to learn effectively. One approach to this problem is to manually scale the features so they are in similar ranges across environments and units: batch normalization. Since DDPG uses deterministic policy, we must add exploration.
