Deep Reinforcement Learning: From Theory to Practice

Course website ↗

Course overview

University of Colorado Boulder's course on scaling reinforcement learning with neural function approximation, with an emphasis on implementation, stability, and evaluation.

Topics covered

  • Function approximation, fitted value iteration, and the interaction between bootstrapping and off-policy learning.
  • DQN, replay buffers, target networks, Double DQN, dueling networks, and prioritized experience replay.
  • REINFORCE, baselines, actor–critic methods, and an introduction to PPO, DDPG, and SAC.
