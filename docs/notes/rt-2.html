VLA_2. RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control

Brohan et al.

Original paper ↗

Introduction

Semantic reasoning and visual interpretation capabilities are useful for robots. Since robots need low-level action(not text) we cannot directly apply VLMs to robots, which generally address only the high-level robotic planning.

Can large pretrained VLMs be integrated directly into low-level robotic control to boost generalization and enable emergent semantic reasoning?

By tokenizing the actions into text tokens, we can train the model can be directly trained to act as instruction following robot policies. The unified output space enables model weights to be shared across language and action tasks, without introducing action-only components. We call this category of models as Vision-Language-Action(VLA)

VLA models

Pre-trained VLMs

PaLI-X: An Encoder-Decoder vision-language model featuring a ViT backbone, specialized for superior visual/spatial perception. And 1000 integers have a unique token, so we simply associate the action bins to token. PaLM-E: A decoder-only multimodal model built on the PaLM LLM backbone, leveraging massive web-scale text and code pre-training for exceptional commonsense reasoning, logic, and mathematical calculation.

Robot-action fine-tunig

We represent actions as language tokens in the model’s output. Action encoding is based on the RT-1 model method, the continuous dimensions of actions are discretized into 256 bins. This requires reserving 256 tokens to serve as action tokens. For PaLI-X, we just associate the action bins to unique integer tokens. At PaLM-E, we overwrite the 256 least frequently used tokens to represent actions. Co-fine-tuning robotics data with the original web data can improve robot performance. To allow the model to accurately process instructions semantically, it must also be trained to produce text outputs; therefore, prompting is configured to restrict outputs to action tokens only during robot-action tasks, while permitting full natural language outputs for all other tasks.

Real-time inference

Using multi-TPU cloud service, 55B paramter RT-2-PaLI-X model can run at 1\~3Hz. For 5B model can run 5Hz.

Experiments

1. Seen/unseen task performance

For seen task, we use the same instructions in RT-1. Note that these in-distribution evaluations still have vary placement of objects and factors, requiring the skills to generalize. The strength of VLAs lies in transferring more generalizable and semantic concepts from their internet-scale pretraining data.

2. Emergent capabilities of RT-2

We do not expect such transfer to enable new robot motions, but semantic and visual concepts. There are 3 categories of emergent capabilities. We can see that PaLM-E model has an edge on math reasoning, which results from its pre-training data mixture containing a higher proportion of mathematical content.

3. Parameter count and design decisions

In this experiment, we use RT-2-PaLI-X model because of its flexibility in terms of the model size. Co-fine-tuning keeps the original data around the fine-tuning part of training, so it allows the model to not forget its previous concepts.

4. Chain-of-thought reasoning

Include Plan step. This data augmentation schema acts as a bridge between VQA datasets and manipulation datasets.

Limitations

  1. Robot cannot perform new motions.
  2. Real-time inference becomes a major bottleneck.
  3. Small number of available VLMs that can be used to create RT-2.
