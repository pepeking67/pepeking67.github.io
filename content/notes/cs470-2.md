### Naive Bayes parameter learning
Naive: the attributes (features) are conditionally independent of each other, given the class (label)
$$
Given\ A, B, C, D, \\P(A \cap B \cap C \cap D) = P(A)P(B)P(C)P(D)
$$
Bayes: a follower of statistical methods based on Bayes’ thm
Bayes’ thm: 
$$
P(H|E)=\frac{P(E|H) \cdot P(H)}{P(E)}\\
P(H|E): posterior, P(E|H): likelihood, P(H): prior
$$
Basyian learning method는 prior ditribution을 보고 probabilistic inference를 진행하는 것
<empty-block/>
classification 상황에서 naive bayes를 적용하면 모든 features가 independent 하다고 가정

## MLE / MAP
### MLE
MLE: Maximum Likelihood Estimation
1. write the expression for the likelihood of the data as a function of  parameters
2. write down the derivates of the log likelihood with respect to each parameter
3. find the parameters suth that the derivates are zero
<empty-block/>
<details>
<summary>ex) Estimating the parameters of a biased coin</summary>
	Setup:
	1. P(Heads) = $`\theta`$, P(Tails) = 1 - $`\theta`$
	2. flips are independent and identically distributed (iid)
	3. D: sequence of head or tail
	<empty-block/>
	MLE steps:
	1. Formulate the objective function $`P(D | \theta) = \theta ^ {\alpha H + 1}(1-\theta)^{\alpha T}`$
	2. MLE of $`\theta`$ that maximizes the probability of D
	$$
	\theta * = argmax\ P(D|\theta)\\
\ \ \ \ \ \ \ \ \ \ = argmax\ ln\ P(D|\theta)\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ = argmax ln\ \theta ^ {\alpha H}(1-\theta)^{\alpha T}
	$$
	1. Optimize the objective function 
	$$
	\frac{d}{d\theta}ln\ P(D|\theta) = \frac{d}{d\theta}[\theta ^ {\alpha H}(1-\theta)^{\alpha T}]\\
= \frac{d}{d\theta}[\alpha H \ ln \theta + \alpha T\ ln(1-\theta)]=0
	$$
	⇒ $`\theta * = \frac{\alpha H}{\alpha H + \alpha T}`$
	<empty-block/>
	Problem: values not seen in the training data
	만약에 feature가 training set에서 나타나지 않은 값이면 likelihood가 0이다. 새로운 데이터에 예측하지 못하게 되어 오버피팅 문제를 발생하게 된다.
	<empty-block/>
	이를 해결하기 위해 Laplace Smoothing 방식을 사용한다.
</details>

## Regression
![](notion-file-block://9ef0ad69-a5f8-82a7-8aa4-0165324a09f0/a6f5cf43-3733-447f-acba-1f23796f7ace?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
![](notion-file-block://e990ad69-a5f8-8219-af75-8102eac02025/58f6b7d7-2923-493a-8336-82b0d07c1fb0?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
$$
\bigtriangledown_w(xw-y)^T(xw-y)=0\\
\bigtriangledown_w(w^Tx^Txw-2w^Tx^Ty+y^Ty) = 0\\
2x^Txw-2x^Ty=0\\
\therefore w=(x^Tx)^{-1}x^Ty
$$
이런 식으로 linear regression을 통해서 가장 값들을 잘 표현하는 직선의 기울기 w를 구할 수 있다.
![](notion-file-block://6640ad69-a5f8-8379-aaaa-8176baede6ca/ad0883d1-d4d8-4988-a4aa-646626028c76?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
### Regularization
위와 같은 오버피팅을 해결하기 위해서 정규화를 적용함
adding a preference for one solution in its hypothesis space to another
![](notion-file-block://9b90ad69-a5f8-8314-ba40-01da620eac58/fa0e46e6-d7e8-408f-ac12-0662bbab49ab?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
J(w)는 objective function으로 이를 최소화하는 것을 목표로 함.
이처럼 $`w^2`$을 objective function에 추가하면 w가 작아져야 objective function이 작아지니까 이를 통해 w의 크기를 작게 유지하여 과도하게 데이터 패턴을 따르지 않게 된다.
이에 대한 strength는 $`\lambda`$ 값을 통해 조절한다.

## Properties of Perceptrons
1. Separability: true if some parameters get the training set perfectly correct
2. Convergence: if the training set separable, perceptron will eventually converge
3. Mistake Bound: the maximum # of mistakes related to the margin or degree of separability
<empty-block/>
이 때 문제는 데이터가 linearly하게 separable하지 않는다면 노이즈가 발생한다.

### Computational Cost
computational cost of forward pass: one add-multiply operation per weight
$$
z_i = \sum_{j}w_{ij}^{(1)}x_j+b_i^{(1)}
$$
computational cost of backward pass: two add-multiply operations per weight 
$$
\bar w_{ki}^{(2)}=\bar y_k h_i\\
\bar h_i = \sum_k \bar y_k w_{ki}^{(2)}
$$
Rule of thumb: the backward pass is about as expensive as two forward passes
multilayer perceptron에서는 # of layers에 비례하고, # of units per layer의 제곱에 비례한다
