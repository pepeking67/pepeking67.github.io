Transformer(3) Self-attention & Transformer

트랜스포머 모델을 이해하기 위해서는 어텐션 매커니즘을 이해해야 하고, 이를 위해서 seq2seq 모델에 대한 이해가 선행되어야 한다. 이는 RNN 기반의 자연어 처리 모델 중 번역을 위해 만들어졌다. 트랜스포머를 이해하기 전에 RNN, LSTM, Seq2seq에 대한 설명은 아래에 정리했다.

NLP

Seq2seq

개요

트랜스포머 모델은 Attention is All You Need라는 논문의 제목처럼 RNN을 사용하지 않고 전적으로 어텐션 매커니즘에 기반을 둔 모델이다. 시퀀스 간의 복잡한 의존성을 효과적으로 학습하고, 훈련 시간을 단축시키기 위한 모델이다. RNN을 사용하는 이전 모델들과 달리, 트랜스포머는 병렬 처리가 가능하여 대규모 데이터셋에서 효율적인 처리가 가능하다. Self Attention 매커니즘을 사용하여 자신을 구성하는 부분끼리 연관성을 찾는다. 위의 그림처럼 트랜스포머는 RNN 기반 Seq2seq와 비슷하게 인코더 디코더 구조를 사용한다. Seq2seq에서는 인코더, 디코더가 각각 하나의 RNN이 t개의 time step을 가지는 구조였다면, 트랜스포머는 RNN을 사용하지 않고 인코더, 디코더가 각각 N개로 구성된다.

Self Attention

트랜스포머의 핵심 매커니즘으로 자신을 구성하는 부분끼리의 연관성을 찾고자 할 때 사용된다.

예를 들어 왼쪽 그림처럼 I = student이기 때문에 이 둘의 연관성이 높은 것을 알 수 있다.

Self-attention은 다음과 같은 특징을 가진다.

  1. 병렬 처리: 각 단어가 다른 단어들과 동시에 상호작용하므로 병렬 처리가 가능하다.
  2. 긴 종속성: 멀리 떨어진 단어들 사이의 관계를 쉽게 알 수 있다.
  3. 위치 불변성: positional encoding을 통해 각 단어의 위치 정보를 사용한다.

기존의 어텐션과 self-attention을 비교하면 다음과 같다.

Self-Attention 기존 Attention
Query 입력 문장의 모든 word vector t 시점의 디코더의 은닉 상태
Keys 입력 문장의 모든 word vector 모든 시점의 인코더 은닉 상태들
Values 입력 문장의 모든 word vector 모든 시점의 인코더 은닉 상태들

Self-Attention(Q,K,V) Q: 입력 벡터가 다른 단어와 얼마나 관련이 있는지 평가하는 데 사용한다. K: 쿼리와 상호작용하여 집중(attention)할 단어를 결정한다. V: 실제로 네트워크가 사용하게 되는 정보이다. 대략적인 과정은 다음과 같다.

  1. 각 입력 단어를 고차원 벡터로 word embedding한다.
  2. 이 임베딩 벡터를 Q, K, V로 변환하기 위해 WQ,WK,WVW_Q, W_K, W_VWQ​,WK​,WV​를 사용한다.
  3. 이 둘을 내적하여 Q, K, V 벡터를 얻는다.

이 때 각 가중치 벡터들은 모델의 학습 과정에서 최적화된다.

Attention value

기존의 attention score와 마찬가지로 Q와 K 벡터를 내적하여 유사도를 측정한다(QKTQK^TQKT).

dk=dmodelnum_headsd_k=\frac{d_\text{model}}{\text{num}\_\text{heads}}dk​=num_headsdmodel​​

이 때 dmodeld_\text{model}dmodel​은 입력 문장의 단어 벡터의 차원이고, num_heads는 하이퍼파라미터이다. num_heads는 병렬로 어텐션을 수행할 때 병렬의 개수를 의미한다. 이 attention score에 softmax 함수를 취하여 attention distribution을 얻고 이를 V와 가중합하여 attention value를 얻는다.

Multi-head Attention

위에서 attention value를 구할 때 dmodeld_\text{model}dmodel​ 차원을 가진 단어 벡터를 num_heads로 나눈 차원 dkd_kdk​를 가지는 Q, K, V 벡터로 바꾸고 계산했다. 이는 어텐션을 병렬로 사용하기 위함이다. 이렇게 병렬로 처리도니 attention head는 concatenate한다. 이 행렬은 다시 또 다른 가중치 행렬 WoW^oWo을 곱한다. 결과적으로 행렬의 크기가(seq_len,dmodel)(\text{seq\_len}, d_\text{model})(seq_len,dmodel​)이 되는데 이는 인코더에 입력한 문장 행렬과 크기가 같다.

Padding Mask

문장 행렬을 구성하기 위해 문장의 길이를 맞추기 위해 <PAD> 토큰으로 빈 공간을 채우게 되는데 이 토큰을 attention 연산에서 제외(masking)하기 위한 과정이다. Attention score에 <PAD> 토큰 자리에 −∞-\infty−∞를 더해준다. 그러면 소프트맥스 함수를 지나면서 해당 값이 0이 되어 단어 간 유사도를 구할 때 <PAD> 토큰이 반영되지 않게 된다.

Positional encoding

기존에 RNN이 자연어 처리에 유용했던 이유는 단어의 위치에 따라 정보를 순차적으로 입력 받아 처리해서 단어의 위치 정보를 가질 수 있다는 점에 있다. 트랜스포머는 단어를 순차적으로 입력 받지 않기 때문에 다른 방식으로 단어의 위치 정보를 받아야 한다. 그래서 각 단어의 임베딩 벡터에 위치 정보들을 더하여 모델의 입력으로 사용하는데, 이를 positional encoding이라고 한다.

PE(pos, 2i)=sin(pos/100002i/dmodel)PE(pos, 2i+1)=cos(pos/100002i/dmodel)PE_{(pos,\ 2i)}=sin(pos/10000^{2i/d_{model}})\\PE_{(pos,\ 2i+1)}=cos(pos/10000^{2i/d_{model}})PE(pos, 2i)​=sin(pos/100002i/dmodel​)PE(pos, 2i+1)​=cos(pos/100002i/dmodel​)

트랜스포머는 위의 사인, 코사인 함수의 값을 임베딩 벡터에 더해주어 단어의 순서 정보를 준다. pos는 입력 문장에서의 임베딩 벡터의 위치를 나타내며, i는 임베딩 벡터 내의 차원의 인덱스를 의미한다. 수식을 보면 인덱스가 짝수이면 사인, 홀수인 경우에는 코사인 함수의 값을 사용한다.

Encoder

입력 시퀀스의 각 단어를 고차원 벡터로 임베딩하고, 단어 순서를 반영하기 위해 positional encoding을 수행한다. 이후 각 입력 벡터에 대해 Q, K, V 벡터를 생성하고 self-attention을 수행한다. 이 과정에서 multi-head attention을 수행한다. 마지막으로 fully connected layers로 구성된 신경망을 통해 비선형 변환을 수행한다. 이 때 residual connection을 사용하여 모델이 원래 입력을 참조할 수 있게 한다. 정규화 과정은 시퀀스의 정보를 유지하기 위해 layer normalization을 사용한다. 최종적으로 인코더의 출력은 단어 간의 상호 작용, 유사성, 문맥 정보에 대한 정보들을 포함하고 있다.

Decoder

디코더의 input도 인코딩과 마찬가지로 임베딩 벡터로 변환하고 positional encoding을 수행한다. Seq2seq와 같은 RNN 계열의 디코더는 단어를 매 시점마다 순차적으로 입력받기 때문에 현재 시점을 포함한 이전 시점에 대한 단어들만 참고할 수 있지만, 트랜스포머는 문장 전체를 입력받는다. 그래서 이를 방지하기 위해 masked multi-head self-attention을 수행한다. Look-ahead mask를 통해 마스킹이 이루어진다. 이 첫번째 서브층의 self-attention의 다른 점은 attention score에 마스킹을 적용한다는 점이다.

위와 같이 자신보다 미래에 있는 단어들은 참고하지 못하도록 마스킹한다. 지금까지 self-attention을 통해 입력 단어 간의 상호 관계, 출력 단어 간의 상호 관계를 계산했다. 이를 기반으로 인코더의 self-attention value와 디코더의 self-attention value를 이용하여 입력과 출려 단어 간의 상호관계를 파악한다. 즉, 기존의 attention을 사용한다. 그림에서 인코더에서 2개, 디코더에서 1개의 화살표가 있는데 이는 Query vector는 디코더, Key, Value vectors는 인코더로부터 얻는 것을 확인할 수 있다. 이를 통해 얻어진 attention value(= context vector)로 다음 단어를 예측한다. 이 벡터를 fully connected layer 신경망으로 비선형 변환을 수행한다. 이후 Linear에서 선형 변환을 통해 차원을 줄여서 출력 벡터의 크기를 줄여준다. 이후 소프트맥스 함수를 통해 확률이 가장 높은 단어를 최종적으로 출력한다.
