$`f(N)=O(g(N))`$ if $`\exist`$positive constants $`c`$ and $`N_0`$ s.t. $`f(N)\leq c\cdot g(N)`$ for all $`N \geq N_0`$

# Breadth-First Search (BFS)
expand shallowest node first
frontier is a FIFO queue
깊이 순서대로 탐색
<empty-block/>
expands the shollowest unexplored node in the frontier of the search tree
time complexity: $`O(b^d)`$
space complexity: frontier nodes: $`O(b^d)`$, explored nodes: $`O(b^{d-1})`$
![](notion-file-block://ca20ad69-a5f8-8357-8855-81bf8ce9bb8a/e4956e5c-4720-4c47-ad48-f2c9b12c1be0?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
complete? → yes
optimal? → yes if the path cost is a nondecreasing functon of depth

# Depth-First Search (DFS)
[expand a deepest node first](https://olrlobt.tistory.com/35)
frontier is a LIFO stack
<empty-block/>
time complexity: if m is finite, $`O(b^m)`$ ← worst case
space complexity: frontier set이 single path from the root to the leaf node의 정보와 sibling nodes on the path that are unexplored 정보를 저장하기 때문에 $`O(bm)`$이다
<empty-block/>

<empty-block/>

h is **admissible **if it never overestimate the cost of reaching the goal ⇒ $`h(n) \leq h^*(n)\ \ \  \forall n`$

### Optimality of A\* Search (Proof)
Suppose sub-optimal goal B is on the fringe(테두리)
some ancestor n of A is on the fringe too
Claim: n will be expanded before B
![](notion-file-block://6650ad69-a5f8-8361-be84-819ae41cacce/413ac116-336a-4efd-973f-86bc46d4b3be?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
$$
f(n)=g(n)+h(n)\\f(n)\leq g(A)\\g(A)=f(A)\\ \\g(A)<g(B)\\f(A)<f(B)
$$
1. f(n) ≤ f(A)
2. f(A) \< f(B)
3. n expands before B ← f(n) ≤ f(A) \< f(B)
⇒ all ancestors of A expand before B
⇒ A expands before B
⇒ A\* search is optimal
<empty-block/>
### Consistency (monotonicity)
An admissible heuristic h is called **consistent **if for every state s and for every successor s’, 
$`h(s) ≤ c(s,s’) + h(s’)`$
triangle inequality와 비슷
admissible보다 stricter한 조건이다
![](notion-file-block://dcd0ad69-a5f8-82a4-a369-81b0a1446a86/b9bb7dd6-6e78-43b4-bb1a-c3e5edcbf6f8?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
If h is consistent and all costs are non-zero, then f values cannot decrease along any path
(pf)
Claim: f(n’) ≥ f(n) where n’ is the successor of n
g(n’) = g(n) + c(n,a,n’)
f(n’) = g(n) + c(n,a,n’) + h(n’) ≥ f(n)
<empty-block/>
### Admissibility and Consistency
main idea: estimated heuristic costs ≤ actual costs
admissibility: h ≤ actual cost to goal
consistency: heuristic arc cost ≤ actual cost for each arc: h(A)-h(C) ≤ cost(A to C)
<empty-block/>
### Optimality of graph A\* search
If h(n) is consistent, then values of f(n) along any path are non-decreasing
A\*이 확장할 노드 n을 고르면 optimal path to that node를 찾을 수 있다
first goal node must be an optimal solution
all nodes later will have higher f values

### Evaluating heuristics
A\* generate N nodes to find a goal at depth d
b\* branching factor: uniform tree of depth d would have in order to contain N+1 nodes
$$
N+1=1+b^*+(b^*)^2+\cdots +(b^*)^d\\N+1=((b^*)^{d+1}-1)/(b^*-1)\\N\approx (b^*)^d \Rightarrow b^*\approx \sqrt[d]{N}
$$
<empty-block/>
heuristics form a semi-lattice: max of admissible heuristics is admissible
$`h(n)=max(h_a(n),h_b(n))`$
trivial heuristics: bottom of lattice = zero, top of lattice = exact heuristic
trade-off: accuracy vs computation time
zero일수록 시간은 빠르지만 정확도가 내려감
![](notion-file-block://90d0ad69-a5f8-829d-aaf5-81f72cc85b0d/5ab39bbe-6b0b-4691-ba0d-e97bed163918?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)

repeated puzzle solving을 통해 weights를 학습한다

optimization: unimportant how the goal was reached ← 그냥 최종 최적 상태가 solution이 됨
예를 들어 N-queens 문제에서 서로 공격하지 않도록 하는 퀸들의 배치 자체가 해답이 됨
→ generic setup
problem은 combinatorial structure를 가질 수 있다 (with constraints)
모든 possible solutions를 search하는 것은 불가능하다
⇒ local search
<empty-block/>
state space: 해결책이 되는 공간으로 set of complete configurations이다
조건을 만족하는 configuration을 찾는다
keep a single current state (path는 유지하지 않는다)
perform local improvement
전체 search tree를 조사할 필요가 없어서 메모리가 적게 들고 이렇게 해도 충분히 좋은 solution을 얻을 수 있다
<empty-block/>
local search는 현재의 해를 기준으로 그 주변부(vicinty)를 조사하여 점진적으로 해를 개선해 나간다

### Simulated annealing
bad moves도 허용 → to escape local maxima
decrease the size and the frequency of bad moves over time
![](notion-file-block://f3b0ad69-a5f8-82cf-a87d-01767e85f297/2f143bd1-7f61-4c0f-a1a4-70f6f9e20939?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
여기서 p를 어떻게 선택하는가?
현재 상태의 value를 E라 하고 다음 상태의 value를 E’이라 했을 때 E \> E’이라 가정한다
두 value의 차이가 너무 크면 현재 상태가 좋을 확률이 높기 때문에 p를 작게 설정한다
만약 차이가 작으면 현재 상태가 그렇게 좋은 local maxima 근처는 아니라고 볼 수 있기 때문에 p를 높게 설정해서 잘 벗어날 수 있게 한다
⇒ Bolatzman distribution을 사용한다 $`p=exp(-\frac{E-E_i}{T})`$
temperature T → T가 클수록 p가 커진다 ($`e^0`$) 
이 T는 시간이 지날수록 작아지기 때문에 초기에는 bad move로 잘 이동하다가 나중에는 이동하지 않게 된다
위 식에서 보면 E와 Ei의 차이가 클수록 p가 작아져서 위에서 말한 p의 선택 방식에도 잘 부합하는 것을 확인할 수 있다

# Constraint satisfaction problems (CSPs)
constraint satisfaction: method where each variables has a value that satisfies all the constraints on the variable
<empty-block/>
3 components
1. X: set of variable \{X1, …, Xn\}
2. D: set of domains \{D1, …, Dn\}, one for each variable
3. C: set of consraints
<empty-block/>
solution ⇒ complete **variable assignment** that is consistent (satisfies all the given constraints)
key idea: constraint를 사용해서 search space에서 탐색할 영역을 줄이고 general inference algorithms과 연관된 representation language를 사용한다 ← heuristic처럼 특정 문제에만 적용되지 않고 일반적인 상황에서도 해결할 수 있도록 한다

### Backtracking search
uninformed search
<empty-block/>
search component)
at each step, consider assignments to a single variable
variable assignments are commutative 
→ \[WA=red then NT=green\] = \[NT=green then WA=red\]
<empty-block/>
 constraint propagation)
oncremental goal test → check the constraints as the variable assigned
⇒ only assign values which do not conflict previous assignments
<empty-block/>
backtracking search)
DFS with incremental variable assignment and constraint checking
back track when failure is detected

### Arc consistency
directed arc X → Y is **consistent **iff $`\forall x \ of \  X, \exist y \ of\  Y \ s.t.\ (x,y)\ \text{satisfies the constraint btw X and Y}`$
<empty-block/>
remove values from the domain of X to enforce arc-consistency
arc consistency detects failures earlier
<empty-block/>
이 방식은 forward checking보다 1 step 빠르게 확인하기 때문에 빠르다
domain of variable이 없어지면 backtrack한다

### Entailment
one thing follows from another
$$
KB\models \alpha
$$
KB entails sentence $`\alpha`$ ↔ $`\alpha`$ is true in all worlds where KB is true
이 개념은 한국어로 함의라고 한다
ex)
KB containing ‘the Giants won’ and ‘the Reds won’ entails ‘either the Giants won or the Reds won’
no breeze in \[1,1\] entails no pit in \[1,2\], \[2,1\]
<empty-block/>
entailment는 semantics를 기반으로 한 relationship btw sentences (⇒ syntax)
⇒ entailment is different than inference
<empty-block/>
### Models
model이란 truth가 evaluated될 수 있는 structured world이다
If $`\alpha`$ is true in m, then m is a model of a sentence
M($`\alpha`$) is the set of all models of $`\alpha`$
Then $`KB \models \alpha`$ iff $`M(KB)\sube M(\alpha)`$

### Inference
$`KB \vdash_i\alpha`$ ⇒ sentence $`\alpha`$ can be dereived from KB by procedure i
1. soundness: i is sound if whenever $`KB \vdash_i\alpha`$, it is also true $`KB \models \alpha`$
구조론적으로 참일 때 의미론적으로도 참이면 sound하다라고 한다
1. completeness: i is complete if whenever $`KB\models \alpha`$, it is also true $`KB\vdash_i\alpha`$
참인 명제는 논리적으로 참이라고 증명할 수 있다

## First-Order Logic (FOL)
propositional logic은 world가 facts들을 contain한다고 가정했다면
FOL은 (predicate logic) objects, predicates, functions, variables를 가진다고 가정한다
object ← constant, predicate ← relation
functions are relations with single value for each object
<empty-block/>
Atomic sentence = predicate(term1, …, term_n) or term1 = term2 ⇒ return T/F
Term = function(term1, …, term_n or constant or variable ⇒ return values
<empty-block/>
atomic sentences를 connectives를 통해 complex하게 만든다

### Problems
1. Frame problem ← 상태가 변할 떄 변하지 않는 요소들을 어떻게 표현할 것인가
2. Qualification problem ← action이 성공하기 위한 모든 조건들을 정의할 수 없다 (너무 많다)
3. Ramification problem ← (파생 효과 문제) action들의 파생 효과들을 어떻게 처리할 것인가
<empty-block/>

⇒ maintains goal stack

PDDL은 시스템을 preconditions와 post-conditions를 통해서 표현한다 (PDDL includes FOL)
<empty-block/>
components)
objects, predicates, initial state, goal specification, actions/operators

### Bayes Rule
$$

$$

### Independence
two variables are independent if P(x,y)=P(x)P(y)
P(x\|y)=P(x), $`X\perp\!\!\!\perp Y`$
<empty-block/>
**Conditionally independence)**
X and Y are conditionally independent given Z if $`P(x,y,z)=P(x|z)`$
$`P(A\cap B|C)=P(A|C)P(B|C)`$
<empty-block/>
