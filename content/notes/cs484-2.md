# Multiview Geometry
- **Structure**: 같은 3D point에 대한 2개 이상의 projections가 주어졌을 때 그 point의 3D coordinates를 계산한다 → scene geometry
- **Stereo correspondence**: 이미지의 point가 주어졌을 때 다른 이미지들에서 대응되는 points는 어디인가? → stereo matching
- **Motion**: 두 개 이상의 이미지들의 corresponding points가 주어졌을 때 camera parameters를 계산한다 → camera geometry

## Diffuse Reflection
The apparent brightness of a diffuse surface is the same regardless of the observation direction
![](notion-file-block://0670ad69-a5f8-83cf-b845-81390d82633d/7ba0450c-9f6f-45a2-9395-56407106dc81?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
light intensity는 tangent plane에 비춰지는 영역의 크기에 비례하는데, 이 영역의 크기는 $`cos\theta`$에 비례한다
⇒ intensity를 \<N, L\>로 계산 $`I=\rho(\vec{N}\cdot \vec{L})`$
여기서 각도가 커질수록 어두워진다 ⇒ $`\vec{N}\cdot \vec{L}`$를 shading이라 한다
<empty-block/>
![](notion-file-block://9d10ad69-a5f8-82b0-9100-81931cf7ce0e/1ee1b9ea-7ece-4721-8c42-bfda7c91d5ca?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
I: observed intensity
$`\rho`$: diffuse reflectance
$`\vec{L}`$: light direction (unit vector)
<empty-block/>
reflectance 값을 알면 위 방정식을 solve할 수 있다
⇒ $`\rho N=(L^TL)^{-1}L^TI`$

$`\rho=||\rho N||`$

## Feature invariance
### Invariance vs Covariance
Invariance: independent of image transformation
⇒ features(transform(image)) = features(image)
<empty-block/>
Covariance: change accordingly wrt transformation
⇒ features(transform(image)) = transform(features(image))
<empty-block/>
Covariant detection ⇒ Invariant description
<empty-block/>

Photometric transformation: $`I\rightarrow aI+b`$

gradient만 취급하면 b를 무시할 수 있다

find a hyperplane that maximizes the margin between the positive and negative examples
input: $`S = \left( \left( \mathbf{x}_i, y_i \right), \ldots, \left( \mathbf{x}_n, y_n \right) \right), \quad \mathbf{x}_i \in \mathbb{R}^N, \quad y_i \in \{-1, 1\}`$

support vector의 경우 $`x_iw+b=\pm \ 1`$
distance between point and hyperplane: $`z=\frac{|x_iw+b|}{||w||} = \frac{1}{||w||}`$
⇒ margin = $`\frac{1}{||w||}+\frac{1}{||w||}=\frac{2}{||w||}`$
<empty-block/>
1. maximize the margin $`\frac{2}{||w||}`$
2. classify all training examples
![](notion-file-block://cf00ad69-a5f8-82af-89c4-013ee5581735/9e70537c-f044-47a7-867f-2d2c3b638de7?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
quadratic programming problem 형태로 생각할 수 있다
![](notion-file-block://ca50ad69-a5f8-8388-a28f-81beadac7b97/43f08036-b652-4281-8a14-c25191b35a1e?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
⇒ solution: $`w=\sum_i \alpha_iy_ix_i`$
$`\alpha`$: learned weight
$`x_i`$: support vector
<empty-block/>
$`b = y_i-w \cdot x_i`$
classification function (decision boundary) 
![](notion-file-block://a570ad69-a5f8-821b-b36e-8180ffe0ff65/2d491a99-94c2-4702-97ac-9aad98abcc39?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
이 식을 보면 이 값은 test point x랑 support vector $`x_i`$의 inner product를 통해 구한다
optimization problem을 solving하는 것은 모든 training points pairs에 대한 inner product $`x_i \cdot x_j`$를 계산하는 것을 포함한다

### Non-linear SVM
![](notion-file-block://ac20ad69-a5f8-82b8-9e97-014acaba5beb/b61076f7-862f-4378-ad0b-fa4aeb03bc1d?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
이런 식으로 linearly separable할 수 있지만
![](notion-file-block://db00ad69-a5f8-83e7-bba3-81e336c09604/cd32343d-f504-48e6-8b53-f6f2e2877851?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
이런 식으로 되어 있으면 linear하게 분리할 수 없다
higher-dimensional space로 매핑하여 이를 linear하게 구분할 수 있다
![](notion-file-block://8ee0ad69-a5f8-82f2-b3b0-0197986d1691/32beca5d-77ba-41ca-9458-d02d5ebcbfce?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
- **Kernel Trick**
higher-dimensional feature space로 매핑하는 함수를 $`\phi(x)`$라고 했을 때 
이를 직접적으로 구하는 것이 아니라 inner product의 형태를 구하는 것이다
⇒ Kernel function $`K(x_i, x_j)=\phi(x_i)\cdot \phi(x_j)`$
이를 통해 original feature space의 nonlinear decision boundary를 구할 수 있다
<empty-block/>
![](notion-file-block://8f40ad69-a5f8-83db-90f3-0180a810ceab/86f7475a-7932-47e1-93a9-be2239c2dfe8?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
처음의 예시에서 처럼 $`\phi(x)=(x,x^2)`$
![](notion-file-block://4f80ad69-a5f8-8250-a482-8175c8b68dd1/dfed0c30-4b63-40d4-b55d-3edad33b457e?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
$`\phi(x)\cdot \phi(y)= (x,x^2)\cdot (y,y^2)=xy+x^2y^2`$
$`K(x,y) = xy+x^2y^2`$
← polynomial kernel
<empty-block/>
summary
1. pick an image representation (bag of features)
2. choose kernel function for that representation
3. compute matrix of kernel values btw all pairs of training examples
4. feed kernel matrix into SVM solver to obtain support vectors and weights
5. test → compute kernel values btw test example and all support vectors, and combine them with learned weights to yield the value of the final decision function
<empty-block/>
SVM에는 multi-class를 직접적으로 수행할 수 있는 능력이 없다
그래서 multiple binary SVMs를 통해 이를 구현한다
1. one vs others
2. one vs one → votes
<empty-block/>
장점)
많은 SVM 패키지가 있고, kernel based framework는 매우 강력한 성능을 가진다. 그리고 매우 작은 training set에 대해서도 잘 작동하여 현실에서 쓰기 용이하다
<empty-block/>
단점)
multi-class를 직접적으로 수행할 수 없다
모든 examples의 pairs에 대한 matrix of kernel values를 계산해야 하고 (training time ≥ $`O(n^2))`$
large scale problem에 대해 SVM을 학습하는 것이 매우 오래 걸린다

### Logistic Regression
그래서 데이터끼리의 correlation을 어느정도 고려하여 확률로 나타내고자 하는 게 로지스틱 회귀
linear vs logistic
![](notion-file-block://81a0ad69-a5f8-82ce-b252-01639c5cfbd0/bde63063-8182-48e9-aeaa-e362b646b6bb?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
logistic regression은 linear regression의 결과를 사용해서 예측값을 확률로 표현하여 분류 모델로 사용하는 것이다
우리가 구하고자 하는 확률의 구조는 binomial distribution을 따르기 때문에
$`P(y_i|\pi )=\pi^{y_i}(1-\pi)^{1-y_i}`$ 로 나타난다
이를 통해 likelihood function을 구하면 (likelihood는 P와 다르게 파라미터 순서가 다름)
![](notion-file-block://6ff0ad69-a5f8-8328-9301-01abf1dc2528/c97ba4fb-d228-49fb-aad6-a2b2d88161dd?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
![](notion-file-block://6db0ad69-a5f8-8361-bafb-014f185b1335/bbf00047-d3a4-4331-af39-2070f30f0a8a?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
이런 식으로 나타난다
여기서 우리는 linear regression의 방식을 결합한다
logit function을 먼저 정의해야 하는데 $`logit(\pi_i)=log(\frac{\pi_i}{1-\pi_i})=X_i\beta`$로 logit 함수가 linear combination 형태로 나타난다 
이렇게 정의하는 이유는 $`\pi`$를 구하는 게 목표였는데 이거의 범위가 0-1이고, 이를 odds = pi/(1-pi)로 나타낸 게 0-infinity, log를 취하면 실수 범위가 된다 ⇒ 이를 통해 선형적으로 범위의 제한을 받지 않고 만들 수 있음 
이거를 다시 logit 변환을 시키면 $`\pi_i=\frac{e^{X_i\beta}}{1+e^{X_i\beta}}`$가 되는데 이는 sigmoid 함수 형태로 0-1 사이의 값을 가지게 되어 확률로 생각할 수 있다 ← 이 함수를 로지스틱 함수라 한다
즉, 주어진 데이터의 선형 결합으로 예측 확률을 구성할 수 있고 이러한 구성에서 우리가 구해야 하는 것은 선형 결합의 가중치이다 ⇒ 이를 구하기 위해 최대우도법을 사용한다
<empty-block/>
이를 위의 likelihood function에 넣으면 선형 결합의 weight를 파라미터로 가지게 된다
![](notion-file-block://dfb0ad69-a5f8-83da-b80e-01d3eb5a34ce/9ae21d01-e7e4-4ec4-bd6f-8883015fa8d6?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
계산의 평의성을 위해 log-likelihood를 사용하면 다음과 같다
![](notion-file-block://1730ad69-a5f8-824b-a708-018b8ba8a2ae/bf936557-535a-4866-9321-51e3adaed077?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
![](notion-file-block://d4f0ad69-a5f8-8316-bb0d-8199772ac88b/9d41e4a2-a76c-4b5b-820c-e9be95df976a?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>

### K-means clustering
minimize the sum of squared Euclidean distances btw points x and their nearest cluster centers m
![](notion-file-block://ba20ad69-a5f8-826d-9c21-81785bf91945/9fe35869-7eb0-4484-8fc6-52c4f6457766?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
알고리즘)
초기에는 임의로 k개의 cluster centers를 배치한다
다음 과정을 수렴할 때까지 반복한다
- 가장 가까운 center에 데이터들을 배치한다
- cluster center를 데이터들의 mean으로 다시 계산한다
<empty-block/>
clustering은 **visual vocabulary**나 **codebook**을 학습하는 일반적인 방법이다
unsupervised learning
각 cluster center는 codevector가 된다
codebook은 separate training set에서 학습될 수 있다
codebook은 quantizing features에 사용된다
vector quantizer는 feature vector를 codebook의 가장 가까운 codevector의 index로 매핑한다
<empty-block/>
codebook = visual vocabulary = codevector의 집합, 즉 클러스터 중심들의 집합
codevector = visual word
<empty-block/>
그러면 이 vocabulary size를 어떻게 정하는가?
너무 작으면 visual words가 모든 patches에 대해 설명하지 못한다
너무 크면 quantization artifacts, overfitting이 발생한다
<empty-block/>
vocabulary tree를 사용하면 계산속도가 더 빠르다
<empty-block/>
feature descriptor들을 nearest neighbor k-means를 통해 분배한다
예를 들어 50개의 visual words가 있고 220개의 featuers가 있다고 했을 때 BoW representation은 50 dim을 가지는 히스토그램이고 각 bin의 feature descriptor 개수를 합치면 220이다
<empty-block/>
이 히스토그램은 normlized되어야 한다 (← L2 norm like SIFT)
이를 통해 image size와 # of features가 bag of features magnitude에 영향을 미치지 않도록 한다
<empty-block/>
이 feature space (space of the histogram vectors)는 learnable hyperplane에 의해 나누어 진다
(0이면 decision boundary에 존재)
1 vs all (A vs not A) linear SVM을 통해 BoW feature space를 # of classes로 classify한다
<empty-block/>
classifier들이 테스트 case를 평가하여 점수를 부여하는데 이게 모두가 음수인 경우에도 가장 큰 값으로 분류한다

→ similar pixels는 같은 segment에 있고 dissimilar pixels는 다른 segment에 있어야 한다
<empty-block/>

## Generalization Error
bias: difference btw expected prediction and correct value ← error due to inaccurate assumptions/simplifications
<empty-block/>
variance: amount that the estimate of the target function will change if different training data was used

### Underfitting
model is too simple to represent all relevant class characteristics
⇒ high bias (few dof) and low variance
high training error and high test error
![](notion-file-block://b8f0ad69-a5f8-8289-8b1f-81250837ce2c/458c69bc-bd3a-4a04-9a70-bcb04f91e2e2?space_id=a572f2a2-f7b0-4923-b5c0-74f5db67bcd1&name=image.png)
<empty-block/>
### Overfitting
model is too complex and fits irrelevant characteristics (noise) in the data
low bias (many dof) and high variance
low training error and high test error
