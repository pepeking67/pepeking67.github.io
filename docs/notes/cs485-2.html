Bag of Words (BoW)

visual object categorization

새로운 이미지가 주어졌을 때 이 이미지를 효율적으로 categorize하는 것이다 이 과정은 generic해야 한다 variation을 처리할 수 있어야 한다

이를 위해서 bag of (visual) words 기법을 사용한다 bag of visual words는 histogram of occurrences of particular image patterns in a given image BoW의 방식은 효율적이고 affine transformation (translation, scaling, reflection, rotation)에 invariant 이외에도 occlusion, lighting, intra-class variation에도 잘 적용할 수 있다

Bag of Words

text를 bag of its words로 간소화한다 문법이나 단어 순서들을 disregarding한다 (multiplicity는 유지) frequency of occurrence of each word를 feature로 사용하여 classification에 사용한다

visual words: base elements to describe an image object image는 collection of visual words independent features를 codewords라 한다 (representativeof similar patches) 그러면 이미지의 patch들은 codeword들로 매핑되고 codewords의 histogram으로 나타낼 수 있다 테스팅에서는 이 BoW를 feature vector로 사용하여 image의 class를 찾는다

테스트를 진행할 때 새로운 이미지의 descriptors를 추출할 때 categorization task와 무관한 변환에 대해서 inavriant해야 한다 vocabulary size가 충분히 커서 이미지를 잘 표현할 수 있어야 하지만 너무 크면 노이즈까지 표현하게 되는 문제가 생기기 때문에 적절한 크기를 선택하는 것이 중요하다 codeword에는 눈, 코, 입과 같이 intuitive meaning을 가지지는 않는다

트레이닝을 할 때 테스트와 마찬가지로 터음에 디스크립터를 추출하고, 클러스터링을 통해 클러스터 중심들로 코드북(vocabulary)을 만든다. 이 코드북을 사용해서 BoW를 추출한다 이를 feature vector로 사용해서 multi-class classifier를 사용한다 전반적으로 가장 높은 정확도를 보이는 vocabulary size와 classifier parameter를 결정한다

왜 디스크립터가 affine transformation에 invariant해야 하냐면 디스크립터는 repeatable해야 하기 때문이다 가장 대표적인 디스크립터 추출 방식은 SIFT이다 4*4 grid의 8 orientations의 Gaussian gradient를 계산하여 이를 디스크립터로 사용한다 (128dim)

visual word (real-valued descriptor vectors)는 Euclidean distance를 통해 비교한다 K-means clustering을 통해 이 디스크립터들을 k개의 그룹으로 나눈다(초기에 랜덤 means 배치) 1. 가장 가까운 클러스터 중심으로 데이터들을 배치한다 2. 데이터 mean으로 새로 클러스터 중심을 계산한다 위 과정이 수렴할 때까지 반복하는 것이 K-means clustering이다 (local optima에 수렴 가능성 높음) ⇒ visual codebook (cluster centers = codewords)

이 방식의 단점은 트레이닝 이미지가 많은 descriptor를 가지면 비효율적이다 위에 사진처럼 테스트 사진을 codeword에 배치하는 것을 vector quantization process라고 한다
