Markov Decision Process (MDP)

classical 강화학습은 MDP를 따른다 agent, environment, state, action, reward로 구성되어 있다

Markov Property

Given the present state, the future and the past are independent action outcomes depend only on the current state next state depends on the action and the current state past action과 state는 미래의 일에는 영향이 없다고 가정한다

action에 확률을 부여 ← stochastic ↔ deterministic

MDP는 <S, A, T, R, γ\gammaγ>로 표현할 수 있다 S: set of states A: set of actions T: state transition probability matrix Tss′a=p(St+1=s′∣St=s, At=a)T^a_{ss'}=p(S_{t+1}=s'|S_t=s,\ A_t=a)Tss′a​=p(St+1​=s′∣St​=s, At​=a) ← dynamic T(S, A, *)들의 합은 1이다 R: reward function Rsa=E[Rt+1∣St=s, At=a]R^a_s=E[R_{t+1}|S_t=s,\ A_t=a]Rsa​=E[Rt+1​∣St​=s, At​=a]

The Goal of RL

deterministic의 경우 optimal plan(seq of actions) from start to goal MDP의 경우 optimal policy를 구하는 것을 목표로 한다 π∗:S→A\pi^*:S\rightarrow Aπ∗:S→A policy는 각 state에 대한 action을 부여한다 optimal policy는 expected utility를 최대화하는 것이다 (reward 최대화가 아님)

Discounting Rewards

cumulative reward: Rt=rt+rt+1+...+rnR_t=r_t+r_{t+1}+...+r_nRt​=rt​+rt+1​+...+rn​ discounted cumulative reward: Rt=rt+γrt+1+γ2rt+2+...+γn−trnR_t=r_t+\gamma r_{t+1}+\gamma ^2r_{t+2}+...+\gamma^{n-t}r_nRt​=rt​+γrt+1​+γ2rt+2​+...+γn−trn​ discount factor γ\gammaγ는 0\~1 사이의 값으로 현재의 보상이 미래의 보상보다 더 가치 있게 만든다 terminal point 이외의 부분에서의 reward를 위의 R(s) 값으로 설정했을 때 값이 클수록 천천히 end point로 가고 값이 작을수록 end point가 음수이든 양수이든 상관없이 빠르게 끝내려 한다

RL은 reward를 최대화하는 게 아니라 utility를 최대화하는 것이다 immediate reward + sum of the long term rewards ← Bellman optimality equation

How to determine the optimal policy?

Find a strategy with lower probability not to complete a task 여기서 보면 가운데로 가는 것은 제대로 못 끝낼 가능성이 높기 때문에 돌들을 피해서 가는 것을 선호한다

Value (utility) function

reward function과 다르게 value function은 long-term value of state s를 부여한다 1. state-value(Vπ(s))V_\pi(s))Vπ​(s)): expected return from state s and then following policy π\piπ 1. action-value(Qπ(s,a)Q_\pi(s,a)Qπ​(s,a)): expected return from state s, taking action a, and then following policy (Q(s,a)임)

policy π\piπ is a distribution ofver actions given states π(a∣s)=P[At=a∣St=s]\pi(a|s)=P[A_t=a|S_t=s]π(a∣s)=P[At​=a∣St​=s]

policy는 각 state에 대해 어떤 action을 행할 지를 명시한다 current state에 의존한다 not the history ⇒ policies are stationaty(time-independent) stochastic의 경우 잘못 갈 수도 있는데 이 때 각 state마다 행동을 부여하면(policy) 다시 복귀하기가 수월함

Bellman Optimality Equation

The value of a state under an optimal policy must equal the expected return for the best action from that state

  1. optimal state-value function: V∗(s)=maxπVπ(s)V_*(s)=max_\pi V_\pi(s)V∗​(s)=maxπ​Vπ​(s)
  2. optimal action-value function: Q∗(s,a)=maxπQπ(s,a)Q_*(s,a)=max_\pi Q_\pi(s,a)Q∗​(s,a)=maxπ​Qπ​(s,a) Q∗(s,a)=E[Rt+1+γV∗(St+1)∣St=s,At=a]Q_*(s,a)=E[R_{t+1}+\gamma V_*(S_{t+1})|S_t=s,A_t=a]Q∗​(s,a)=E[Rt+1​+γV∗​(St+1​)∣St​=s,At​=a]

How to find an optimal policy?

Planning: exhaustive search, dynamic programming ← 지금 하려는 게 이거임 Reinforcement learning: Monte Carlo method, TD method

Dynamic Programming

  1. Optimal substructure: 하위 문제의 최적해를 기반으로 상위 문제를 해결할 수 있다
  2. Overlapping subproblems: 하위 문제의 해를 저장했다가 다시 사용할 수 있다 위 두가지를 만족해야 DP를 적용할 수 있다

MDP의 경우 Bellman equation이 recursive decomposition, value function이 solution을 저장하고 reuse할 수 있기 때문에 DP를 적용할 수 있다

1. Value Iteration

  1. 각 state의 utility를 계산한다
  2. state utility를 사용해서 각 state의 optimal action을 구한다

Bellman optimality equation를 통해 value iteration을 진행한다 Bellman optimality eq: V∗(s)=max⁡a∑s′T(s,a,s′)[R(s,a,s′)+γV∗(s′)]V_*(s) = \max_a \sum_{s'} T(s, a, s') \left[ R(s, a, s') + \gamma V_*(s') \right]V∗​(s)=maxa​∑s′​T(s,a,s′)[R(s,a,s′)+γV∗​(s′)] 이를 통해 VI를 구현하면 Vk+1(s)←max⁡a∑s′T(s,a,s′)[R(s,a,s′)+γVk(s′)]V_{k+1}(s) \gets \max_a \sum_{s'} T(s, a, s') \left[ R(s, a, s') + \gamma V_k(s') \right]Vk+1​(s)←maxa​∑s′​T(s,a,s′)[R(s,a,s′)+γVk​(s′)] VI는 fixed-point solution method이기 때문에 수렴하는 해가 있다

  1. V0(s)=0V_0(s)=0V0​(s)=0
  2. Vk+1(s)←max⁡a∑s′T(s,a,s′)[R(s,a,s′)+γVk(s′)]V_{k+1}(s) \gets \max_a \sum_{s'} T(s, a, s') \left[ R(s, a, s') + \gamma V_k(s') \right]Vk+1​(s)←maxa​∑s′​T(s,a,s′)[R(s,a,s′)+γVk​(s′)]
  3. 수렴할 때까지 위 과정 반복

이 알고리즘의 시간 복잡도는 O(S2A)O(S^2A)O(S2A)이다

예) Vk+1(s)←max⁡a∑s′T(s,a,s′)[R(s,a,s′)+γVk(s′)]V_{k+1}(s) \gets \max_a \sum_{s'} T(s, a, s') \left[ R(s, a, s') + \gamma V_k(s') \right]Vk+1​(s)←maxa​∑s′​T(s,a,s′)[R(s,a,s′)+γVk​(s′)] 표시된 부분 V2((3,3))V_2((3,3))V2​((3,3))를 계산하고자 한다 V2((3,3))=∑s′∈SP(s′∣(3,3),right)[R((3,3),right)+0.9V1(s′)] =0.8[0+0.9∗1]+0.1[0+0.9∗0]+0.1[0+0.9∗0]=0.72V_2((3,3))=\sum_{s'\in S}P(s'|(3,3),right)[R((3,3),right)+0.9V_1(s')]\\ \quad \quad \quad \quad \ = 0.8[0+0.9*1]+0.1[0+0.9*0]+0.1[0+0.9*0]=0.72V2​((3,3))=∑s′∈S​P(s′∣(3,3),right)[R((3,3),right)+0.9V1​(s′)] =0.8[0+0.9∗1]+0.1[0+0.9∗0]+0.1[0+0.9∗0]=0.72

이를 수렴할 때까지 혹은 threshold까지 반복하여 V∗V_*V∗​를 구한다

이후 optimal policy를 구하려면 다음을 계산한다 π∗(s)=arg⁡max⁡a∑s′T(s,a,s′)[R(s,a,s′)+γV(s′)]\pi^*(s) = \arg\max_a \sum_{s'} T(s, a, s') \left[ R(s, a, s') + \gamma V(s') \right]π∗(s)=argmaxa​∑s′​T(s,a,s′)[R(s,a,s′)+γV(s′)]

2. Policy Iteration

  1. Policy evaluation: calculate utilities for some fixed policy(not optimal) until convergence
  2. Policy improvement: update policy

policy evaluation 과정: fixed policy에 대해서 value가 수렴할 때까지 단순히 Bellman updates를 적용한다 이 경우에 Bellman equation은 linear system이고 max operator를 사용하지 않기 때문에 O(n3)O(n^3)O(n3) 시간이 걸린다 iteration 마다 O(S2)O(S^2)O(S2)이 걸린다

policy improvement 과정: 위에서 얻은 fixed utility value를 통해 one-step look-ahead 방식을 통해 더 좋은 plicy가 있는지 확인한다 ⇒ policy extraction πi+1(s)=arg⁡max⁡a∑s′T(s,a,s′)[R(s,a,s′)+γVπi(s′)]\pi_{i+1}(s) = \arg\max_a \sum_{s'} T(s, a, s') \left[ R(s, a, s') + \gamma V^{\pi_i}(s') \right]πi+1​(s)=argmaxa​∑s′​T(s,a,s′)[R(s,a,s′)+γVπi​(s′)]

VI와 PI 모두 optimal values를 계산한다 PI가 시간이 덜 걸린다

Reignforcement Learning

Goal: optimal way to make decisions delayed reward: decisions now can impact things much later ex) 시험 공부하면 나중에 시험에서 잘 본다 ⇒ 두 가지 challenge가 있다 - Planning: decisions은 immediate benefit 뿐만 아니라 longer-term consequences를 포함한다 - Learning: temporal credit assignment is hard = 어떤 요소가 나중에 high or low rewards를 주는지 알기 힘들다

selecting action을 할 때 2가지 방식이 있다 - exploitation: make the best decision given current info, risk of missing out on a better reward somewhere else - exploration: gather more information, risk of wasting time & getting negative reward

RL의 mapping from past experiences to action이 policy이다 generalization이 필요한데 일부 states만 과거에 관찰될 수도 있고, 관찰되지 않은 states에 대해서도 일반화할 필요가 있다

Monte-Carlo Methods (MC)

trial-and-error approach complete knowledge를 가정하지 않는다 experience → values, policy

몬테 카를로 방식은 다음 두 가지 방식으로 사용될 수 있다 1. model-free: 환경의 명시적인 모델 (전이 확률, 보상 함수)를 몰라도 최적 정책을 학습할 수 있다 2. simulated: 시뮬레이션으로 학습을 진행할 수 있다

하나의 에피소드가 끝난 뒤에 complete sample returns를 통해 학습을 진행한다 episodic 기반의 문제에만 적용할 수 있다

Goal: policy π\piπ에서의 episodes of experience로부터 V, Q를 학습한다 하나의 에피소드에서의 return 을 보면 total discounted reward 형태이다 MDP에서 value function은 expected return으로 정의된다 MC에서는 이러한 expected return 대신에 empirical mean return을 사용한다 G(S1)=R1+γ\gammaγR2+…=R1+γ\gammaγG(S2) 이런 식으로 계산됨

Incremental MC updates

Goal: update V incrementally after episode S1, A1, R2, …, ST 추가적인 에피소드를 통해 얻은 return G를 현재의 value에 적용하는 방식이다 계산의 효율성을 위해 처음부터 다시 평균을 계산하지 않고 다음과 같은 방식을 사용한다 비정상적인 상황에서는 과거의 데이터를 가지고 평균을 계산하는 것이 오히려 안 좋기 때문에 1/N 부분을 고정된 rate α\alphaα로 둬서 running mean에 집중하는 것이다 ⇒ forget old episodes

DP vs MC

MC → no bootstrapping (bootstrapping: 추정치를 계산할 때 다른 상태의 추정치를 사용한다) estimates for each state are independent can estimate value of a subset of all states

Temporal-Difference Learning (TD)

MC + DP learn directly from episodes of experience model-free → MDP transitions, rewards를 몰라도 된다 learns from incomplete episodes by bootstrapping episodic이 아니여도 된다

Goal: learn VπV_\piVπ​ online from experience under polcy π\piπ

  • incremental every-visit MC: update value V toward actual return G
  • simplest TD learning algorithm TD(0): update value V toward estimated return 부트스트래핑: using one or more estimated and same type of values during the update TD에서 V나 Q를 업데이트 하는데 다음과 같다 이 때 true VπV_\piVπ​를 사용하지 않고 current estimate V (⇒ samping)를 사용한다 ⇒ 그래서 끝까지 갈 필요 없다 ← bootstrapping
  • ϵ\epsilonϵ-greedy: 1-ep 확률로 exploitation, ep 확률로 exploration

MC의 경우 end of episode의 return을 알 때까지 기다려야 한다는 단점이 있다 TD의 경우 매 step마다 learn online할 수 있다

TD는 final outcome이 없어도 학습이 진행된다 TD는 incomplete sequences에서도 진행이 되고 MC는 complete에서만 가능하다 그래서 TD는 continuing (non-terminating) 환경에서도 작동한다 (MC는 불가능)

On/Off policy

on policy: target policy = behavioral policy ⇒ final policy is influenced by the exploration policy ⇒ after policy improvement, cannot reuse experience

off policy: target policy != behavioral policy ⇒ final policy is independent of the exploration policy

SARSA

← on policy learn action-value function Q with TD(0) use transition (St, At, Rt+1, St+1, At+1) for updates policy를 QπQ_\piQπ​를 사용해서 greedily하게 바꾼다 (s,a)가 infinitely many times 방문되거나 policy가 greedy policy에 수렴하면 수렴한다

Q-learning

← off policy Q directly approximates Q* independent of the behavior policy 업데이트 식에서 이미 최적의 방향으로 (max) 진행하고 있기 때문에 behavior policy가 최적일 필요는 없다

Deep RL

예를 들어 Q-table이 10억개 이런 식으로 데이터가 너무 많을 때에는, DL을 활용할 수 있다 여기서 문제가 Q가 지속적으로 업데이트 되기 때문에 타겟이 고정되지 않는다 (non-stationary) prediction을 타겟값에 맞추기 위해 학습이 진행되는데 타겟값이 변해서 불안정해짐 ⇒ moving Q-targets We move the prediction to the target, but we also move the target. → High divergence 이러한 oscillation을 방지하기 위해서 target network를 한 번 더 업데이트 한다 이 손실함수를 통해 prediction과 타겟값의 차이를 줄이는 방향으로 학습할 수 있다

Experience replay

transitions를 replay buffer에 저장하여 무작위로 샘플리한 batch를 사용 ⇒ 효율성을 높이고, 데이터의 상호 관계 (correlation)를 낮춘다
