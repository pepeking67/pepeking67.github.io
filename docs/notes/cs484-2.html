σ\sigmaσ가 너무 작으면 error value가 비슷해진다 ⇒ 그래프를 보면 σ\sigmaσ가 작을 때 거의 수평선으로 되어 있다 너무 크면 least squares와 비슷하게 행동한다

robust fitting은 nonlinear optimization이기 때문에 반복적으로 해결되어야 한다 least squares 방식이 이때의 initialization이 될 수 있다

Random Sample Consensus (RANSAC)

robust fitting은 적은 outliers에 대해서 잘 다룬다

4번 과정에서 error distribution에 대해서 ±2σ\pm 2\sigma±2σ 안에 95%의 점이 있다 (정규 분포) 위 과정들을 반복해서 가장 많은 점을 가지는 직선을 찾는다

assumption) 대부분의 좋은 샘플들은 underlying model을 잘 따른다 안 좋은 샘플들은 single model을 잘 따르지 않는다 그래서 RANSAC이 잘 적용된다

parameters) 1. s model을 표현하는 데 필요한 최소한의 개수로 정한다 ex) 직선이면 2개 1. distance threshold t probability for inlier is p (ex 0.95)가 되도록 설정한다 zero mean Gaussian noise with std σ\sigmaσ → t2=3.84σ2t^2=3.84\sigma^2t2=3.84σ2 1. smaple iterations N ← 적어도 한 번은 정상치가 많이 포함된 샘플을 관측할 수 있을만큼 충분해야 한다

RANSAC은 간단하고 많은 문제에 적용할 수 있고 실제로 작동하기 쉽다는 장점이 있다 parameter가 너무 많고 low inlier ratios일 때는 실패하고 항상 좋은 initialization을 할 수 없다는 단점이 있다

Generalization Error

bias: difference btw expected prediction and correct value ← error due to inaccurate assumptions/simplifications

variance: amount that the estimate of the target function will change if different training data was used

Underfitting

model is too simple to represent all relevant class characteristics ⇒ high bias (few dof) and low variance high training error and high test error

Overfitting

model is too complex and fits irrelevant characteristics (noise) in the data low bias (many dof) and high variance low training error and high test error

Bias-Variance Trade-off

너무 파라미터가 적으면 bias가 커진다 너무 파라미터가 많으면 variance가 커진다

절대적인 true function f가 있다고 가정한다 training dataset D={(x1,t1),…,(xN,tN)} 에 대해서 t = f+ϵ\epsilonϵ and E{ϵ\epsilonϵ}=0 ← 카메라로 찍은 데이터 이런 거도 노이즈가 있기 때문에 라벨에도 에러가 있다

이 D를 가지고 machine learning function g를 approximate f 하기 위해 학습시켜서 prediction y with parameters w를 만들어 낸다

y=g(x,w)y=g(x,w)y=g(x,w)

← mean-squared error는 위와 같이 정의된다

네트워크의 effectiveness를 평가하기 위해서 expectation of MSE를 알아야 한다 이 식은 다음을 통해 정리될 수 있다 이처럼 MSE는 variance of the noise와 MSE between the true function and the predicted values로 decomposed 될 수 있다 이 term은 다음 과정을 통해 더 분해할 수 있다 따라서 expectation of MSE는 다음과 같이 정리될 수 있다 이를 통해 관측할 때의 노이즈 때문에 인공지능 성능을 평가할 때 에러를 피할 수 없음을 수학적으로 증명할 수 있다
